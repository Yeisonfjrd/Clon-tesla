# Clon-tesla — A clone of the Tesla website built with Node and NPM
## Overview
Clon-tesla is a web application that mimics the functionality and design of the official Tesla website. It provides a user interface to explore and interact with the features of the website. The project aims to demonstrate the capabilities of Node and NPM in building a complex web application.

## Tech Stack
* Node
* NPM

## Prerequisites
To run Clon-tesla, you need to have Node and NPM installed on your machine.

## Getting Started
To get started with Clon-tesla, follow these steps:
1. Clone the repository using `git clone https://github.com/user/Clon-tesla.git`
2. Install the dependencies using `npm install`
3. Configure the application by creating a `.env` file with the required environment variables
4. Run the application using `npm start`

## Environment Variables
| Variable | Default | Description |
| --- | --- | --- |
| PORT | 3000 | The port number to run the application on |
